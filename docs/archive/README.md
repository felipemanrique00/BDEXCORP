# Arquivo historico

Os arquivos deste diretorio descrevem versoes anteriores e nao sao instrucoes operacionais atuais. Eles podem citar JSON local, schemas removidos, credenciais antigas, URLs de teste ou resultados que nao representam a copia `BDEX_PRODUCAO_SAAS`.

Use somente os documentos diretamente em `docs/` para implantacao, seguranca, backup e status de producao.
